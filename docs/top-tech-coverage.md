# Top tech companies: what this tool can and cannot search

Checked on 2026-10-27 for **127 well-known tech companies**. The list is my own selection of large and well-known US tech employers, not an official ranking.

**Rule:** a company is searchable only if its job board is reachable through a documented, public, read-only feed that is meant for this use (Greenhouse, Lever, Ashby and SmartRecruiters public posting APIs). Company career websites are **not** scraped, and endpoints that exist only as a website's private back end are not used.

**Result: 60 of 127 are searchable.** 65 have no usable public feed, and 2 more have a public board with only a token posting or two.

### Why these are not included

* **Workday** (16 here): the job list comes from an undocumented back-end address of the website. There is no documented public API and no statement that this use is permitted, so it is not used.
* **Phenom, iCIMS, Eightfold, Oracle, SAP, Avature and similar** (19 here): no public, documented posting feed.
* **Own sites** such as Apple, Google, Amazon, Microsoft, Meta, Netflix (30 here): proprietary; no documented public feed, and scraping websites is not done by this tool.

If a company you care about is missing, check its careers page: if its address looks like `boards.greenhouse.io/NAME`, `jobs.lever.co/NAME`, `jobs.ashbyhq.com/NAME` or `jobs.smartrecruiters.com/NAME`, add NAME to your `companies.yaml`.
